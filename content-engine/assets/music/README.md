# Music for the auto-editor

Put royalty-free tracks here (`.mp3`, `.m4a`, `.aac`, `.wav`). They are not committed to git.

- Use only music you have the rights to use on TikTok, Instagram, and YouTube: e.g. a paid
  library whose license covers social platforms, or free libraries such as the YouTube Audio
  Library (check each track's license, especially for use outside YouTube).
- By default each video gets a track in rotation; you can pick one per video on the idea page.
- Alternative: render with **no music** and add a trending sound in the TikTok/Instagram app when
  you post. Trending audio can help reach, and the app handles licensing.
